# Underwater hero — standalone review

Open [`hero-preview.html`](./hero-preview.html) in a browser from a local checkout. From GitHub’s file view, use **Download raw file** and then open the download. No build, server, or dependencies are required. The page optionally loads web fonts; the artwork and animation are self-contained.

- Use **Light** and **Dark** in the header to compare underwater palettes. Both modes use the same animation.
- A few fish peel away from the two schools, start glowing, and form the CIRIS signet. Its links trace the outer and interior geometry.
- The links fade out over two seconds while the fish trade places along the outline, then fade back in over five seconds. Background schools, whale sharks, stingrays, and jellyfish keep moving independently.
- The scene stops animating offscreen or in hidden tabs and respects the system reduced-motion setting.

This is a design review artifact, not a deployed page. It uses the homepage mockup for context; its copy, product claims, and navigation are not changes to the production site.
