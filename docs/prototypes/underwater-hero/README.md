# Underwater hero — standalone review

Open [`hero-preview.html`](./hero-preview.html) in a browser from a local checkout. From GitHub’s file view, use **Download raw file** and then open the download. No build, server, or dependencies are required. The page optionally loads web fonts; the artwork and animation are self-contained.

- Use **Light** and **Dark** in the header to compare the ocean-blue daylight and deeper navy palettes.
- The opening holds on three fish schools alone for 4.5 seconds. Then fish peel away, start glowing, and form the CIRIS signet over 15 seconds. Reload the page to see the opening from the start.
- The links fade out over two seconds while the fish trade places along the outline, then fade back in over five seconds. The schools and whale sharks keep moving independently behind them.
- The scene pauses offscreen or in hidden tabs. With system reduced motion enabled, it shows the finished signet instead of the opening animation.

This is a design review artifact, not a deployed page. It uses the homepage mockup for context; its copy, product claims, and navigation are not changes to the production site.
